## 一、需求背景

将 VidMuse 前端品牌主题从「AI 音乐视频生成平台」改造为「光希视频内容创作平台」。

### 改造目标
1. **隐藏社区功能**：注释路由/导航/首页相关 UI，**不删除代码**，便于一键回滚
2. **品牌主名替换**：中文 `VidMuse` → `光希`，英文 `VidMuse` → `GuangXi`
3. **首页文案去音乐化**：移除 `MUSIC VIDEOS` / `音乐视频` / `MV` / `音轨` / `导演` 等音乐人导向用语，换为视频内容创作语境
4. **登录/注册页文案去音乐化**：同上
5. **其他页面保持不动**：工作台、项目、媒体库、设置、帮助、Help 内部页文案不改

## 四、命名约定与一致性原则

1. **中文环境**：品牌名统一为 `光希`（不带空格、不带书名号）
2. **英文环境**：品牌名统一为 `GuangXi`（驼峰拼音，与原 `VidMuse` 风格对齐）
3. **副标题**：中文 `视频内容创作平台`、英文未在副标题位置出现，无需翻译
4. **品牌色样式保持不动**：所有渐变色、阴影、动画样式不动，只换文字
5. **未被首页/登录页引用的 i18n key 不改**：`workbench.*`、`audioAnalysis.*`、`storyboard.*`、`timeline.*`、`projects.*`、`library.*`、`settings.*`、`help.*`、`createProjectModal.*`、`exportModal.*`、`common.*`、`nav.*`、`community.*` 全部保留原样
6. **`home.communityMasterpieces`、`home.globalCreativeDynamics` 文案不动**：因 Community Grid section 整段被注释，自然不被引用
