## 要求说明：

- **必须输出为标准 JSON**，可直接用于程序处理、数据库存储、前端展示、AI训练等。
- **多模态融合**：音频特征 + 歌词语义 + 情感语义 + 节奏模式 + 和弦走向 + 动态变化。
- **五秒粒度分析**：每个5秒窗口包含乐器、情绪、歌词摘要、和弦、节奏。
- **结构标签自动标注**：V1, C1, B, S, O 等，符合你截图中的结构化标注
- **结构标签必须使用完整名称**，如：

- `Verse1`（不是 `V1`）
- `Chorus1`（不是 `C1`）
- `Bridge`（不是 `B`）
- `Solo`（不是 `S`）
- `Outro`（不是 `O`）

1. **结构标签必须结合音乐实际情况进行智能判断**，不能硬编码，必须根据：

- 歌词内容（如“副歌”、“桥段”、“结尾”等关键词）
- 音乐情绪变化（如“情绪爆发”、“情绪沉淀”、“器乐主导”）
- 节奏/和弦/动态变化（如“鼓点密集”、“旋律上扬”、“渐弱收尾”）
- 歌曲结构惯例（如“主歌 → 副歌 → 桥段 → 副歌 → Solo → Outro”）

1. **结构标签必须在每个段落中明确标注**，并**在 `structure_segments` 中以完整名称输出**。
